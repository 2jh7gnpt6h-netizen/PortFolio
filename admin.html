Connexion

Cette page écrit directement dans le dépôt GitHub du site. La clé, c'est un jeton d'accès personnel : il reste dans ce navigateur (rien n'est envoyé ailleurs, rien n'est enregistré dans le site).

  1. Ouvrir github.com → jeton d'accès fin
  2. Accès : Only select repositories → ce dépôt
  3. Permissions → Repository permissions → Contents : Read and write
  4. Générer, copier, coller ci-dessous

Un jeton se révoque à tout moment depuis GitHub. Si tu es sur un appareil partagé, décoche la case : il sera oublié à la fermeture de l'onglet.
